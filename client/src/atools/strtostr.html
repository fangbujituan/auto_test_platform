使用说明

  • 在左侧输入原始文本，右侧输入修改后的文本
  • 输入框左侧有固定的行号列，便于定位具体行
  • 若文本是合法 JSON（对象或数组）：
    • 粘贴或失焦会自动按 2 空格缩进格式化
    • 自动切到JSON 视图，行号列上的 ▼ 点击可折叠对应块，▶ 点击可展开
    • 在 JSON 视图中双击任意位置即可进入编辑模式，光标会定位到双击的行和列，失焦后自动格式化并返回 JSON 视图；右上角标签仅显示当前模式状态
  • 点击对比文本按钮显示差异，顶部会弹出 Toast 提示本次差异数量
  • 绿色高亮表示新增内容
  • 红色高亮表示删除内容
  • 黄色高亮表示修改内容
  • 启用同步滚动可使原始文本、修改文本和对比结果三者按百分比同步滚动
  • 拖动编辑区与对比结果之间的分隔条可上下调整两区高度（含最小 / 最大限制）
  • 点击清空文本可重置所有输入区域
  • 点击「对比文本」后，若两侧文本均为合法 JSON，会出现JSON 自动排序按钮：递归将对象按 key 字母升序（a→z，大小写不敏感、数字按数值感知，如 a2 排在 a10 前）排列，数组保持原有顺序，排序后自动重新对比
